# Local Speech-to-Text Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `STT_PROVIDER=local` runs Silero VAD, Smart Turn v3.2 and faster-whisper `large-v3-turbo` on the laptop, and yields one transcript per finished turn, in Vietnamese or English.

**Architecture:** A pure state machine (`voice/turns.py`) turns 16 kHz frames plus speech probabilities into finished-turn audio, asking an injected `is_complete` callback at each pause. `voice/local_stt.py` loads the three models and exposes `transcribe_local(pcm24k)`, which has the same shape as the HF `transcribe_stream`. Both CLIs pick the provider with `stt_provider()`.

**Tech Stack:** Python 3, numpy, onnxruntime (already a dependency), faster-whisper 1.2.x (bundles `faster_whisper/assets/silero_vad_v6.onnx` and a numpy `FeatureExtractor`), huggingface-hub for the Smart Turn download.

**Spec:** [docs/superpowers/specs/2026-11-19-local-stt-design.md](../specs/2026-11-19-local-stt-design.md)

## Global Constraints

- `STT_PROVIDER`: `hf` (default when empty) or `local`. Any other value is a config error with exit code 2.
- Defaults: `STT_MODEL=large-v3-turbo`, `STT_PAUSE_MS=200`, `STT_TURN_THRESHOLD=0.5`, `STT_MAX_SILENCE_MS=2000`. Speech starts at Silero probability ≥ `VAD_THRESHOLD` (existing setting, default 0.5).
- `STT_DEVICE`: `cpu | gpu`. Empty means GPU if CUDA is found, else CPU. GPU uses `compute_type="int8_float16"`, CPU uses `"int8"`.
- 16 kHz everywhere after resampling. Silero frames are 512 samples (32 ms) with a 64-sample context. Lead-in is 300 ms. Smart Turn sees the last 8 s, zero-padded at the start.
- The Smart Turn file is `smart-turn-v3.2-cpu.onnx` from HF repo `pipecat-ai/smart-turn-v3`, saved under `models/smart-turn/`.
- Whisper language is limited to `vi` or `en`. Use `beam_size=1`, `vad_filter=False`, `condition_on_previous_text=False`.
- New dependencies go only in a new extra: `stt = ["faster-whisper>=1.2,<2", "huggingface-hub>=0.25"]`. Install with `uv sync --extra stt`. `faster_whisper` is imported lazily, so the HF path works without it.
- `HF_TOKEN` is required for speech only when the provider is `hf`.
- `EnergyVAD` and barge-in are not touched. The HF provider's behaviour and tests stay unchanged.
- Every feature change updates `docs/FEATURES.md` and its usage doc.

## Review Focus

1. **Short noise (a cough or click, < 250 ms of speech)** must not become a turn, and Whisper must not hallucinate text for it. Covered by test `test_short_blip_is_not_a_turn` (Task 1), plus dropping segments with `no_speech_prob > 0.6` (Task 2).
2. **A `--file` that ends mid-sentence, with no trailing silence,** must still yield that last sentence. Covered by `test_flush_returns_open_turn` (Task 1) and `test_transcribe_local_flushes_at_end` (Task 2).
3. **Whisper running for 0.5 s must not freeze the event loop,** because ducking and barge-in read audio in the same loop. Covered by `test_transcribe_runs_off_loop` (Task 2).
4. **No GPU, or missing CUDA/cuDNN libraries,** must give a one-line error naming `STT_DEVICE=cpu`, not a traceback. Covered by `test_gpu_load_failure_message` (Task 2).
5. **A typo in `STT_PROVIDER`** must be a config error with exit 2, not a silent fallback to HF. Covered by `test_bad_stt_provider_exits_2` (Task 3).

  - `class TurnDetector: __init__(self, settings: TurnSettings, is_complete: Callable[[np.ndarray], float])`, `feed(self, frame: np.ndarray, prob: float) -> np.ndarray | None`, `flush(self) -> np.ndarray | None`. The returned array is the turn's 16 kHz float32 audio, lead-in included.

```python
def test_complete_turn_ends_at_pause():
    calls = []
    det = TurnDetector(TurnSettings(), lambda a: calls.append(len(a)) or 0.9)
    out = run(det, speech(1000) + silence(224))
    assert len(out) == 1 and len(calls) == 1

def test_incomplete_turn_waits_then_resumes_same_turn():
    det = TurnDetector(TurnSettings(), lambda a: 0.1)
    assert run(det, speech(800) + silence(500) + speech(800)) == []
    out = run(det, silence(2016))
    assert len(out) == 1 and len(out[0]) >= 16 * 1600  # both speech parts in one turn

def test_max_silence_ends_turn_when_smart_turn_says_no():
    det = TurnDetector(TurnSettings(), lambda a: 0.0)
    assert run(det, speech(1000) + silence(1984)) == []
    assert len(run(det, silence(64))) == 1

def test_smart_turn_asked_once_per_pause():
    calls = []
    det = TurnDetector(TurnSettings(), lambda a: calls.append(1) or 0.0)
    run(det, speech(1000) + silence(1500))
    assert len(calls) == 1

def test_lead_in_kept():
    det = TurnDetector(TurnSettings(), lambda a: 1.0)
    out = run(det, silence(1000) + speech(500) + silence(224))
    assert len(out[0]) >= 16 * (300 + 500)

def test_short_blip_is_not_a_turn():
    calls = []
    det = TurnDetector(TurnSettings(), lambda a: calls.append(1) or 1.0)
    assert run(det, speech(160) + silence(2500)) == [] and calls == []

def test_flush_returns_open_turn():
    det = TurnDetector(TurnSettings(), lambda a: 0.0)
    run(det, speech(1000))
    assert det.flush() is not None and det.flush() is None

def test_smart_turn_gets_at_most_8s():
    seen = []
    det = TurnDetector(TurnSettings(), lambda a: seen.append(len(a)) or 1.0)
    run(det, speech(12000) + silence(224))
    assert seen == [8 * 16000]

def test_resampler_ratio_across_odd_chunks():
    r = Resampler24to16()
    pcm = (np.ones(24000, np.int16) * 1000).tobytes()
    total = sum(len(r.feed(pcm[i:i + 1001])) for i in range(0, len(pcm), 1001))
    assert total == 16000

def test_settings_from_env():
    s = TurnSettings.from_env({"STT_PAUSE_MS": "300", "STT_TURN_THRESHOLD": "0.7",
                               "STT_MAX_SILENCE_MS": "", "VAD_THRESHOLD": "0.4"})
    assert (s.pause_ms, s.turn_threshold, s.max_silence_ms, s.vad_threshold) == (300, 0.7, 2000, 0.4)
```

Note on `test_resampler_ratio_across_odd_chunks`: 1001 is odd, so it also checks that a split int16 sample is carried over.

- [ ] **Step 3: Implement `turns.py`**

The resampler keeps every 3 input samples and emits 2 outputs: `x0` and `(x1 + x2) / 2`. Add the comment `shortcut: linear 3:2 resample without low-pass filter; switch to a polyphase filter if Whisper accuracy suffers on sibilants`.

The detector's states:
- **idle:** keep a ring buffer of the last `lead_ms` of frames.
- **speaking** (entered when prob ≥ `vad_threshold`).
- **paused** (silence counted in ms).

Rules:
- On the first silent frame where `silence_ms >= pause_ms`, call `is_complete(last 8 s, zero-padded at the start)` once. If the result is ≥ `turn_threshold`, end the turn.
- `silence_ms >= max_silence_ms` ends the turn.
- Speech during a pause returns to speaking. The next pause asks again.
- At turn end, if total speech is < `min_speech_ms`, drop the turn without calling `is_complete` and return None.

- [ ] **Step 4: Implement `local_stt.py`**

- **Silero (streaming).** Open `faster_whisper.utils.get_assets_path() / "silero_vad_v6.onnx"` with onnxruntime on CPU. Keep `h` and `c` (each `(1, 1, 128)` float32) and the last 64 samples between calls. Each call runs `{"input": concat(context64, frame512)[None], "h": h, "c": c}` and returns `float(out.squeeze())`. faster-whisper's own `SileroVADModel` resets the state on every call, so it can't be used for streaming.
- **Smart Turn.** If `SMART_TURN_DIR / SMART_TURN_FILE` is missing, download it with `huggingface_hub.hf_hub_download(SMART_TURN_REPO, SMART_TURN_FILE, local_dir=SMART_TURN_DIR)`. Run each turn through these steps:
  1. Normalize as `(a - a.mean()) / sqrt(a.var() + 1e-7)`.
  2. Make features with `faster_whisper.feature_extractor.FeatureExtractor(chunk_length=8)(a, padding=0)`. The result has shape `(80, 800)`.
  3. Run the session with `{"input_features": feats[None].astype(np.float32)}` and return `float(out[0].reshape(-1)[0])`.

  Session options: `ORT_SEQUENTIAL`, `inter_op_num_threads=1`, CPU provider.
- **Whisper.**
  - Device `""` means `"cuda"` if `ctranslate2.get_cuda_device_count() > 0`, else `"cpu"`. Device `"gpu"` means `"cuda"`.
  - Wrap model construction and warm-up in `try` / `except (RuntimeError, OSError, ValueError)`. On failure, raise `SttError(f"Whisper failed to load on {device}: {e}. Try STT_DEVICE=cpu")`.
  - Transcribe in these steps:
    1. `_, _, probs = model.detect_language(audio)`
    2. `lang = pick_language(probs)`
    3. `segments, _ = model.transcribe(audio, language=lang, beam_size=1, vad_filter=False, condition_on_previous_text=False)`
    4. Join `s.text` for the segments with `s.no_speech_prob <= 0.6`, then strip.
- **`transcribe_local`.**
  1. If `models` is None, load it with `await asyncio.to_thread(models_from_env, os.environ)`. Print `  (loading local speech model...)` to stderr first.
  2. For each byte chunk, resample, buffer, and split into 512-sample frames. Feed each frame as `detector.feed(frame, models.vad(frame))`.
  3. For each finished turn, `text = await asyncio.to_thread(models.transcribe, audio)`. Yield it if it isn't empty.
  4. When the source ends, call `flush()` and handle the result the same way.
  5. Log at INFO for each turn: the language, the length in seconds, and the Smart Turn score.
