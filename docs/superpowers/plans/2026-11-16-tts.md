# TTS (Gemini, streamed, saved) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `reachy-demo agent` speaks each answer while Gemini streams it and saves a WAV; `reachy-demo speak "text"` tests TTS alone.
**Architecture:** `voice/tts.py` streams PCM chunks from Gemini SSE; `audio/player.py` pipes them into a player subprocess and saves a WAV at the end; the agent CLI calls a `speak(text)` callback after each completed answer.
**Tech Stack:** httpx SSE, asyncio subprocess, stdlib `wave`. **Spec:** `docs/superpowers/specs/2026-11-16-tts-design.md`

## Global Constraints
- 24 kHz mono s16le PCM. Defaults: `TTS_MODEL=gemini-3.8-flash-tts`, `TTS_VOICE=Kore`, `TTS_PLAYER="ffplay.exe -autoexit -nodisp -loglevel error -f s16le -ar 24000 -ch_layout mono -i -"` (`none` = save only).
- Saved to `data/speech/<YYYYmmdd-HHMMSS>-<n>.wav`, always (even when playback fails).
- TTS or player errors print `  (speech error: …)` and listening continues. No new dependencies. Usage docs updated.

## Review Focus
- Player binary missing (`ffplay.exe` not on PATH): WAV still saved, clear error, agent keeps going.
- Gemini stream breaks mid-answer: the partial audio is saved, then the error is shown.
- Ctrl-C while speaking: the player process is killed, no zombie, exit 0.
- An answer that is empty or only an LLM error: nothing is spoken.
- Player exits early (user closes it): no BrokenPipe traceback.

### Task 2: `play_and_save` (audio/player.py) + tests/unit/test_player.py
`PlayerError`; `async def play_and_save(chunks: AsyncIterator[bytes], *, path: Path, player_cmd: str | None) -> Path`; `def speech_path(directory: Path, n: int) -> Path`.
Tests: the player receives every byte and the WAV holds the same PCM; `player_cmd=None` → save only; missing binary → saved + PlayerError; source error mid-stream → partial WAV saved + error re-raised; player exits early → saved, PlayerError, no traceback.
